01 — About

A defender's mindset, an engineer's toolkit

I'm an undergraduate at Dawood University of Engineering & Technology in Karachi, studying BS Cybersecurity — a program that sits exactly where I want to be: between systems engineering and threat defence.

My work is hands-on. I build small labs, break them on purpose, and document what I learn: hardening a Linux box, capturing traffic in Wireshark, mapping an attack path against my own test app, then writing the fix. I care about the boring parts too — logging, least privilege, patch discipline — because that's where real security lives.

Beyond the terminal, I'm interested in security awareness and digital safety for people who never read a CVE — students, families, small businesses. Good security should be understandable.

SecureWatch‑FIM

Real-time File Integrity Monitoring and incident detection. It builds SHA‑256 cryptographic baselines to detect unauthorised file creation, modification and deletion in critical directories, classifies each event HIGH / MEDIUM / LOW, and exposes a Flask dashboard plus a REST JSON API for baselines and event logs.
